# Scam Execution & Victim Profiling

 About the Project

This project was completed as part of my Data Analytics Internship at Psyliq.

The objective of this project was to analyze U.S. cybercrime patterns and understand:

- Victim demographics and geographical hotspots
- Scammer tactics and urgency keywords
- Payment methods and communication platforms
- Government anti-scam actions
- Future technology opportunities for scam prevention

 Tools Used

- Python
- Pandas
- Matplotlib
- SQLite
- Excel

 Key Insights

- The 60+ age group showed the strongest growth in the analyzed age data.
- California had the highest complaint volume among the supplied 2024 state data.
- "Immediately" was the most frequent urgency keyword in the collected narratives.
- Cryptocurrency was the most frequently observed payment method.
- Phone was the most frequently observed individual communication platform.

 Project Deliverables

1. Python analysis notebook
2. Final analytical report
3. Data matrix containing compiled source data and citations

 Project Structure
